# SIMS Project

This repository contains a C# project developed as part of a university course. The project was created to fulfill academic requirements and demonstrate proficiency in software development concepts taught during the course.

## 📚 Project Overview

The application is a conceptual prototype for an animal adoption platform. It allows users to view animals available for adoption, manage basic animal information, and simulate interactions between users and the system.

## 🛠️ Technologies Used

- C#

## 🎓 Academic Context

This project was developed as part of coursework at the university level. It serves as a demonstration of the skills and knowledge acquired during the course.
